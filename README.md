# Royal Fortune UI

Design a premium, modern casino-style video game UI for a fictional virtual-currency casino game called "Royal Fortune".

The game uses virtual coins only. Do not show real-money deposits, withdrawals, payment methods, cryptocurrency, or cash-out functionality.

Overall visual style

Luxurious modern casino atmosphere

Dark, elegant background

Deep burgundy, black, dark emerald and subtle gold accents

Premium gold borders and highlights

Cinematic lighting

High-quality polished game interface

Sophisticated rather than overly flashy

Slight Art Deco influence mixed with modern mobile/PC game design

Glassmorphism panels with subtle transparency

Soft shadows and realistic depth

Large, highly readable typography

Consistent spacing and alignment

Professional AAA-game UI quality

Main Menu

Create a complete main menu containing:

Game logo: "ROYAL FORTUNE"

Player avatar/profile

Virtual coin balance

Player level and XP progress bar

Daily reward button

Settings button

Shop button for virtual items/coins

"PLAY" primary button

Casino game selection section

Notifications icon

Game Selection

Create attractive game cards for:

Roulette

Blackjack

Slots

Poker

Dice

Each card should contain:

Game artwork

Game name

Short description

Minimum virtual coin requirement

Unlock status

Play button

Locked games should have a visually clear lock state.

Casino Gameplay Screen

Create a polished gameplay interface containing:

Top-left player profile

Top-center current level

Top-right virtual coin balance

Large central game area

Betting controls

Virtual coin denomination buttons

Current bet amount

Win/loss result area

"SPIN", "DEAL", or "PLAY" action button depending on the game

Clear animation-ready UI states

Back button

Settings button

Game history panel

Level Progression

Include a level system:

Level number

XP progress

Level objective

Reward preview

Unlockable content

"LEVEL COMPLETE" screen

Next-level button

Example:
"LEVEL 01 — ROOKIE"
Objective: Reach 2,000 virtual coins
Reward: 500 virtual coins + New Table

Popups

Design matching popup screens for:

Daily Reward

Level Complete

Achievement Unlocked

Insufficient Virtual Coins

Game Rules

Settings

Pause Menu

New Game Unlocked

UX requirements

Make important buttons immediately recognizable

Keep the coin balance highly visible

Make the primary action the visual focus

Use consistent button styles

Use clear hover, pressed, disabled and locked states

Design for both 16:9 desktop screens and responsive layouts

Keep UI elements separated so they can later be implemented as individual Unity UI components

Avoid excessive visual clutter

Deliverables

Generate:

Main Menu

Game Selection Screen

Roulette Gameplay Screen

Blackjack Gameplay Screen

Slots Gameplay Screen

Level Complete Screen

Daily Reward Popup

Settings Popup

Player Profile Screen

Shop Screen using virtual currency

Achievement Screen

Loading Screen

Create a cohesive design system so every screen looks like part of the same game.

Use realistic casino-inspired visual details while making it clearly a fictional video game interface. No real casino branding, no real-world gambling company logos, and no real-money payment UI.
